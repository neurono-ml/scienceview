## Purpose

`SVBandPlot` fills the region between two boundary lines — an uncertainty
interval, a confidence band, a range between two series. It is the visual form
of an interval estimate, and it is what `SVLinePlot` uses to show its
confidence interval.

## Recipe

```
data -> [SVStat::Aggregate + error] -> (lower, upper) -> [no move] -> [SVScale] -> SVMark::Ribbon
```

## Data contract

| Column | Role | Type | Required |
|---|---|---|---|
| `x` | ordering axis | continuous or temporal | yes |
| `lower` | lower boundary | continuous | yes |
| `upper` | upper boundary | continuous | yes |
| `series` | one band each | nominal | no |

Alternatively the band may be *derived*: given `y` and a grouping, the stat
computes the estimate and the interval. Both modes are supported, and the
derived mode is what `SVLinePlot` uses internally.

Accepted representations: dense, sparse, streaming (windowed for the derived
mode).

### Match key

`Category` on the `x` value within a series.

## Acceptance

- [x] Explicit bounds are drawn exactly — `explicit_bounds_are_drawn_exactly`
  in `band_plot_tests.rs` asserts both boundaries at the scaled positions.
- [x] The derived mode produces the interval the estimator defines and marks
      it as approximate when the source is a stream —
  `derived_mode_aggregates_mean_and_standard_deviation` compares the band with
  `SVStat::Aggregate`; `SVBandRenderOutput::is_approximate` reports the
  streaming window.
- [x] Dense, sparse and streaming inputs give the same band for the same
      data — `dense_sparse_and_streaming_agree` compares every path vertex
  within `1e-9`.
- [x] An animated band interpolates both boundaries — the boundaries are paths
      of the `Ribbon` mark, whose boundary property is interpolable in the
  transition kernel; the recipe introduces no discrete boundary property.

## Implementation

- Module: `src/recipes/relational/band_plot/` (builder, composition,
  configuration, data contract, derived contract, decorations, output).
- Tests: `band_plot_tests.rs`, `band_plot_derived_tests.rs`,
  `band_plot_missing_tests.rs`, `band_plot_parity_tests.rs`,
  `band_plot_concurrency_tests.rs`, `band_plot_series_tests.rs`,
  `band_plot_observability_tests.rs` and `band_plot_svg_tests.rs`.
- Figure: `docs/figures/band_plot.svg`, generated by `examples/band_plot.rs`.
- Missing values are expressed as non-finite numbers; the explicit policy is
  `SVBandMissingValuePolicy::Omit` (split the band at the gap) or `Error`.
